# gimma-relat-rio

## Como usar o painel

O arquivo principal é o `index.html`.

### Opção 1 (mais simples)
1. Abra a pasta do projeto.
2. Dê duplo clique em `index.html`.
3. O painel abrirá no navegador padrão.

### Opção 2 (rodando com servidor local)
Use quando quiser evitar bloqueios de navegador em alguns recursos.

```bash
python3 -m http.server 8000
```

Depois abra:

```text
http://localhost:8000
```

## Como baixar o arquivo

### Se estiver no GitHub
1. Clique no botão verde **Code**.
2. Clique em **Download ZIP**.
3. Extraia o ZIP no computador.
4. Abra o `index.html`.

### Baixar só o HTML
No GitHub, abra o arquivo `index.html` e use:
- **Raw** (ou **Download raw file**) para salvar só esse arquivo.

## Observações rápidas
- O painel salva os dados automaticamente no navegador (`localStorage`).
- O botão **Limpar tudo** apaga os campos e os dados salvos localmente.
